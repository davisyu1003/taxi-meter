# 🚕 出租车计价模拟器

基于 React + TypeScript + Vite 构建的出租车计价模拟器，支持 GPS 实时里程模拟、多城市计价规则和行程记录。

## 功能特性

- **实时计价** — 根据行驶里程和时长动态计算费用
- **GPS 模拟** — 利用浏览器 Geolocation API 实时追踪移动距离
- **多城市计价** — 内置深圳、广州、上海、成都四种计价规则
- **自定义计价** — 支持新增、编辑、删除计价方案
- **行程记录** — 每次行程结束后自动保存，可查看历史记录
- **附加费用** — 计费途中可随时添加附加费（如过路费）
- **暗色主题** — 护眼暗色 UI，支持移动端

## 计价规则说明

每种计价方式包含以下参数：

| 参数 | 说明 |
|------|------|
| 起步价 | 前 X 公里内统一收费 |
| 里程费 | 超出起步里程后，按元/公里计费，每 N 米计费一次 |
| 时长费 | 等待/低速行驶费用，前 X 分钟免费，之后每分钟计费 |
| 长途费 | 里程超过 X 公里后，每公里加收费用 |

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

然后打开 `http://localhost:5173`（或终端显示的地址）。

## 生产构建

```bash
npm run build
npm run preview   # 预览构建结果
```

## 技术栈

- React 18 + TypeScript
- Vite 5
- 纯 CSS-in-JS（内联样式，无额外依赖）
